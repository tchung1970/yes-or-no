# 나랑 결혼해 줄래? 💍

A playful, interactive proposal app with a soft pink minimalist interface.

## Live Demo

[https://ai.tchung.org/yes-or-no/](https://ai.tchung.org/yes-or-no/)

## Features

- Soft pink minimalist design with floating hearts
- "예" (Yes) button stays stable and triggers a celebration with confetti
- "아니요" (No) button playfully dodges away when you try to click it
- Fun Korean messages appear as the No button escapes
- Works on both desktop and mobile (touch support)
